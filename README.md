# Netflix Data Visualization

This project explores the **Netflix Titles dataset** using Python and Matplotlib. The goal is to understand the data and visualize different patterns in Netflix movies and TV shows.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## 📊 Visualizations

The project includes:

* Movies vs TV Shows count using a **Bar Chart**
* Content ratings using a **Pie Chart**
* Movie duration distribution using a **Histogram**
* Release year vs number of shows using a **Scatter Plot**
* Top 10 countries by number of Netflix titles using a **Horizontal Bar Chart**
* Movie and TV Show releases over the years using **Line Charts**

## 🧹 Data Cleaning

Basic data cleaning is performed by handling missing values in:

* `country`
* `duration`
* `rating`
